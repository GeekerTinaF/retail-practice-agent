# Skills

Reusable skills for this agent go here.

- `retail-research/` (V0.2) — the method for turning European retail
  research into Geek+ intelligence, following the chain
  market → account → fulfilment → commercial.
  - `SKILL.md` — purpose, workflow, non-negotiables.
  - `evidence-policy.md` — source hierarchy, evidence labels, conflicts,
    gaps, competitor claims.
  - `taxonomy.md` — retail subcategories, countries, news types, account
    roles.
  - `report-spec.md` — 9-section report architecture, executive
    intelligence, account model, competitor section, watchlist schema,
    embedded JSON blocks, QA checklist.
  - `visualization-guidelines.md` — "every chart proves one sentence".
  - `commercial-intelligence-framework.md` — signal categories,
    Intelligence Priority scoring record, Commercial Intelligence Chain.
  - `competitor-observation.md` — how tracked automation vendors
    (`data/competitors.yaml`) are observed and recorded.
