  research into Geek+ intelligence, following the chain
  market → account → fulfilment → commercial.
  - `SKILL.md` — purpose, workflow, non-negotiables.
  - `evidence-policy.md` — source hierarchy, evidence labels, conflicts,
    gaps.

    roles.
  - `report-spec.md` — V0.2 report architecture, KPI discipline, account
    model, watchlist schema, QA checklist.
  - `visualization-guidelines.md` — "every chart proves one sentence".
  - `commercial-intelligence-framework.md` — signal categories,
    Intelligence Priority, Commercial Intelligence Chain.
